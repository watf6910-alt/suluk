// منصة رصد السلوك — ربط Google Sheets (الإصدار 4: حماية بالرمز + أعذار أولياء الأمور + استبانات الأهل + أيقونة الإداريات)
// إعداد الموجّهة الطلابية عواطف الحربي
const SS = SpreadsheetApp.getActiveSpreadsheet();
const PROPS = PropertiesService.getScriptProperties();
const REC_H = ['id','النوع','اسم الطالبة','الصف','الفصل','درجة المخالفة','المخالفة / الممارسة','الإجراء','الدرجات','التاريخ','إشعار ولي الأمر','الراصدة','بيانات'];
const CLS_H = ['id','الصف','الفصل','عدد الطالبات','بيانات'];
const UZR_H = ['id','تاريخ الإرسال','اسم الطالبة','الصف','الفصل','أيام الغياب','نوع العذر','ملاحظة','ولي الأمر','الجوال','المرفق','الحالة','سبب الرفض','اعتمدته','بيانات'];
const SRV_H = ['id','تاريخ الإرسال','الاستبانة','القيمة','اللقاء','الصف','ملخص','بيانات'];
const SRV_N = { needs: 'حصر الاحتياجات', values: 'القيم في المنزل', sat: 'رضا اللقاء', iltizam: 'إقرار الالتزام المدرسي', plansig: 'توقيع خطة' };
const UZR_ST = { pending: 'بانتظار الاعتماد', approved: 'معتمد', rejected: 'مرفوض' };

function tab(name, head) {
  let s = SS.getSheetByName(name);
  if (!s) { s = SS.insertSheet(name); s.appendRow(head); s.setFrozenRows(1); s.setRightToLeft(true); }
  return s;
}
function out(o) {
  return ContentService.createTextOutput(JSON.stringify(o)).setMimeType(ContentService.MimeType.JSON);
}
function rows(s, n) {
  const last = s.getLastRow();
  return last < 2 ? [] : s.getRange(2, 1, last - 1, n).getValues();
}
function parse(v) { try { return JSON.parse(v); } catch (e) { return null; } }
function keyOk(k) {
  const K = PROPS.getProperty('KEY');
  if (!K) { if (k) PROPS.setProperty('KEY', String(k)); return true; }
  return String(k || '') === K;
}
function folder() {
  const id = PROPS.getProperty('UZR_FOLDER');
  if (id) { try { return DriveApp.getFolderById(id); } catch (e) {} }
  const f = DriveApp.createFolder('مرفقات أعذار منصة السلوك');
  PROPS.setProperty('UZR_FOLDER', f.getId());
  return f;
}

function doGet(e) {
  const p = (e && e.parameter) || {};
  const owner = Session.getEffectiveUser().getEmail();
  if (p.who) return out({ ok: true, owner: owner });
  if (p.adm) return admGet(p);
  if (!keyOk(p.key)) return out({ ok: false, error: 'key' });
  if (p.img) {
    const f = DriveApp.getFileById(String(p.img));
    const fid = PROPS.getProperty('UZR_FOLDER');
    let inside = false;
    const it = f.getParents();
    while (it.hasNext()) if (it.next().getId() === fid) inside = true;
    if (!inside) return out({ ok: false, error: 'file' });
    const b = f.getBlob();
    return out({ ok: true, mime: b.getContentType(), data: Utilities.base64Encode(b.getBytes()) });
  }
  const recs = rows(tab('السجلات', REC_H), 13).map(r => parse(r[12])).filter(Boolean);
  const cls = rows(tab('الفصول', CLS_H), 5).map(r => parse(r[4])).filter(Boolean);
  const st = tab('الإعدادات', ['بيانات']).getRange('A2').getValue();
  const uz = rows(tab('الأعذار', UZR_H), 15).map(r => parse(r[14])).filter(Boolean);
  const sv = rows(tab('الاستبانات', SRV_H), 8).map(r => parse(r[7])).filter(Boolean);
  return out({ ok: true, v: 4, owner: owner, records: recs, roster: cls, settings: st ? parse(st) : null, excuses: uz, surveys: sv });
}

// أيقونة الإداريات: رمز خاص لا يفتح إلا غياب اليوم لصف واحد، وتسجيل إرسال الإشعار
function admOk(k) { const K = PROPS.getProperty('ADMKEY'); return !!K && String(k || '') === K; }
function admToday() { return Utilities.formatDate(new Date(), Session.getScriptTimeZone(), 'yyyy-MM-dd'); }
function admGet(p) {
  if (!admOk(p.adm)) return out({ ok: false, error: 'adm' });
  const today = admToday(), g = String(p.g || '');
  const abs = [], sess = [];
  rows(tab('السجلات', REC_H), 13).forEach(r => {
    const x = parse(r[12]);
    if (!x || x.date !== today || x.grade !== g) return;
    if (x.kind === 'abs') abs.push({ id: x.id, name: x.name || '', section: String(x.section || ''), period: x.period || '', status: x.status || '', excuse: x.excuse || '', notified: !!x.notified, nAt: x.nAt || '', nBy: x.nBy || '' });
    else if (x.kind === 'sess') sess.push({ section: String(x.section || ''), period: x.period || '' });
  });
  const st = parse(tab('الإعدادات', ['بيانات']).getRange('A2').getValue()) || {};
  return out({ ok: true, v: 4, d: today, abs: abs, sess: sess, st: { school: st.school || '', region: st.region || '', principal: st.principal || '', phone: st.phone || '' } });
}
function admSent(b) {
  const lock = LockService.getScriptLock();
  lock.waitLock(20000);
  try {
    if (!admOk(b.adm)) return out({ ok: false, error: 'adm' });
    const today = admToday(), R = tab('السجلات', REC_H);
    (b.ids || []).slice(0, 40).forEach(id => {
      const row = findRow(R, id); if (!row) return;
      const x = parse(R.getRange(row, 13).getValue());
      if (!x || x.kind !== 'abs' || x.date !== today) return;
      if (b.undo) { x.notified = false; delete x.nAt; delete x.nBy; }
      else { x.notified = true; x.nAt = new Date().toISOString(); x.nBy = String(b.by || '').slice(0, 40); }
      R.getRange(row, 1, 1, 13).setValues([recRow(x)]);
    });
    return out({ ok: true });
  } finally {
    lock.releaseLock();
  }
}

function findRow(s, id) {
  const f = s.getRange('A:A').createTextFinder(String(id)).matchEntireCell(true).findNext();
  return f ? f.getRow() : 0;
}
function upsert(s, id, vals) {
  const r = findRow(s, id);
  if (r) s.getRange(r, 1, 1, vals.length).setValues([vals]); else s.appendRow(vals);
}
function recRow(x) {
  if (x.kind === 'abs') return [x.id, x.status === 'late' ? 'تأخر' : 'غياب', x.name || '', x.grade || '', x.section || '', '', x.excuse || (x.status === 'late' ? '' : 'دون عذر'), x.period || '', '', x.date || '', x.notified ? 'نعم' : 'لا', x.by || '', JSON.stringify(x)];
  if (x.kind === 'sess') return [x.id, 'تسجيل حضور', '', x.grade || '', x.section || '', '', '', x.period || '', '', x.date || '', '', x.teacher || x.by || '', JSON.stringify(x)];
  if (x.kind === 'note') return [x.id, x.type === 'thanks' ? 'شكر لمعلمة' : 'توجيه لمعلمة', x.to || '', x.grade || '', x.section || '', '', x.text || '', x.period || '', '', x.date || '', '', x.by || '', JSON.stringify(x)];
  if (x.kind === 'plan') return [x.id, 'خطة علاجية', x.name || '', x.grade || '', x.section || '', x.tier || '', x.goal || '', x.status || '', '', x.start || x.date || '', '', x.by || '', JSON.stringify(x)];
  if (x.kind === 'prog') return [x.id, 'لقاء أو برنامج للأسرة', '', '', '', '', x.title || '', x.ptype || '', x.count || '', x.date || '', '', x.by || '', JSON.stringify(x)];
  if (x.kind === 'absact') return [x.id, 'إجراء غياب', x.name || '', x.grade || '', x.section || '', '', x.stage || '', '', '', x.date || '', '', x.by || '', JSON.stringify(x)];
  const exc = x.kind === 'exc' || x.kind === 'comp';
  return [x.id, exc ? 'سلوك متميز' : 'مخالفة', x.name || '', x.grade || '', x.section || '',
    exc ? '' : (x.degree || ''), exc ? (x.practice || x.note || '') : (x.violation || ''),
    x.proc || '', exc ? '+' + (x.points || 0) : (x.pts == null ? '' : '-' + x.pts),
    x.date || '', exc ? '' : (x.notified ? 'نعم' : 'لا'), x.by || '', JSON.stringify(x)];
}

function addExcuse(b) {
  const lock = LockService.getScriptLock();
  lock.waitLock(20000);
  try {
    const U = tab('الأعذار', UZR_H);
    if (U.getLastRow() > 5000) return out({ ok: false, error: 'full' });
    const s = v => String(v || '').slice(0, 300);
    const name = s(b.name), grade = s(b.grade), type = s(b.type);
    const dates = (b.dates || []).map(String).filter(d => /^[0-9]{4}-[0-9]{2}-[0-9]{2}$/.test(d)).slice(0, 15);
    if (!name || !grade || !type || !dates.length) return out({ ok: false, error: 'data' });
    const tz = Session.getScriptTimeZone();
    const today = Utilities.formatDate(new Date(), tz, 'yyyy-MM-dd');
    const sent = rows(U, 3).filter(r => String(r[2]) === name && r[1] instanceof Date && Utilities.formatDate(r[1], tz, 'yyyy-MM-dd') === today).length;
    if (sent >= 5) return out({ ok: false, error: 'limit' });
    let fileId = '';
    const ph = String(b.photo || '');
    if (ph && ph.length < 6000000) {
      const m = ph.match(/^data:(image[/](png|jpeg|webp));base64,(.+)$/);
      if (m) {
        const blob = Utilities.newBlob(Utilities.base64Decode(m[3]), m[1], 'عذر-' + name + '-' + dates[0] + '.' + (m[2] === 'jpeg' ? 'jpg' : m[2]));
        fileId = folder().createFile(blob).getId();
      }
    }
    const id = 'u' + Date.now() + Math.floor(Math.random() * 1000);
    const x = { id: id, at: new Date().toISOString(), name: name, grade: grade, section: s(b.section), dates: dates, type: type, note: s(b.note), parent: s(b.parent), phone: s(b.phone).replace(/[^0-9+]/g, ''), file: fileId, status: 'pending' };
    U.appendRow([id, new Date(), name, grade, x.section, dates.join('، '), type, x.note, x.parent, x.phone, fileId ? 'يوجد' : '', UZR_ST.pending, '', '', JSON.stringify(x)]);
    return out({ ok: true });
  } finally {
    lock.releaseLock();
  }
}

function addSurvey(b) {
  const lock = LockService.getScriptLock();
  lock.waitLock(20000);
  try {
    const S = tab('الاستبانات', SRV_H);
    if (S.getLastRow() > 8000) return out({ ok: false, error: 'full' });
    const type = String(b.type || '');
    if (!SRV_N[type]) return out({ ok: false, error: 'data' });
    const cut = v => typeof v === 'string' ? v.slice(0, 400) : Array.isArray(v) ? v.slice(0, 20).map(cut) : (v && typeof v === 'object') ? Object.fromEntries(Object.keys(v).slice(0, 20).map(k => [String(k).slice(0, 20), cut(v[k])])) : (typeof v === 'number' ? v : '');
    const a = cut(b.a || {});
    const x = { id: 's' + Date.now() + Math.floor(Math.random() * 1000), at: new Date().toISOString(), type: type, value: String(b.value || '').slice(0, 20), prog: String(b.prog || '').slice(0, 60), progTitle: String(b.progTitle || '').slice(0, 120), a: a };
    const sum = type === 'plansig' ? [a.name || '', 'ولي الأمر: ' + (a.parent || ''), String(b.prog || '')].join(' | ') : type === 'iltizam' ? [a.name || '', a.stage || '', a.sec || '', 'ولي الأمر: ' + (a.parent || '')].join(' | ') : type === 'needs' ? [(a.areas || []).join('، '), (a.topics || []).join('، '), a.skills || ''].filter(String).join(' | ') : type === 'values' ? Object.keys(a.r || {}).map(k => k + ':' + a.r[k]).join(' ') + (a.joined ? ' | شاركت: ' + a.joined : '') : 'الفائدة ' + (a.use || '') + ' | يطبقون: ' + (a.apply || '');
    S.appendRow([x.id, new Date(), SRV_N[type], x.value, x.progTitle, a.stage || '', sum, JSON.stringify(x)]);
    return out({ ok: true });
  } finally {
    lock.releaseLock();
  }
}

function doPost(e) {
  const body = JSON.parse(e.postData.contents);
  if (body.op === 'excuse') return addExcuse(body);
  if (body.op === 'survey') return addSurvey(body);
  if (body.op === 'admsent') return admSent(body);
  const lock = LockService.getScriptLock();
  lock.waitLock(25000);
  try {
    if (!keyOk(body.key)) return out({ ok: false, error: 'key' });
    const ops = body.ops || [];
    const R = tab('السجلات', REC_H), C = tab('الفصول', CLS_H), U = tab('الأعذار', UZR_H);
    ops.forEach(op => {
      if (op.op === 'put') upsert(R, op.rec.id, recRow(op.rec));
      else if (op.op === 'del') { const r = findRow(R, op.id); if (r) R.deleteRow(r); }
      else if (op.op === 'class') upsert(C, op.cls.id, [op.cls.id, op.cls.grade, op.cls.section || '', (op.cls.names || []).length, JSON.stringify(op.cls)]);
      else if (op.op === 'delclass') { const r = findRow(C, op.id); if (r) C.deleteRow(r); }
      else if (op.op === 'admkey') PROPS.setProperty('ADMKEY', String(op.code || ''));
      else if (op.op === 'settings') tab('الإعدادات', ['بيانات']).getRange('A2').setValue(JSON.stringify(op.settings));
      else if (op.op === 'uzr') {
        const r = findRow(U, op.id);
        if (r) {
          const x = parse(U.getRange(r, 15).getValue()) || {};
          x.status = op.status; x.reason = op.reason || ''; x.by = op.by || ''; x.doneAt = new Date().toISOString();
          U.getRange(r, 12, 1, 4).setValues([[UZR_ST[x.status] || x.status, x.reason, x.by, JSON.stringify(x)]]);
        }
      }
    });
    return out({ ok: true });
  } catch (err) {
    return out({ ok: false, error: String(err) });
  } finally {
    lock.releaseLock();
  }
}
